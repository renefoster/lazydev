    Same result, fewer keystrokes

    You already run these commands every week. lazydev runs them for you, in order, under a name you pick.

    What you wantBy handWith lazydev
    Start a feature git switch main && git pull && git switch -c feat/login lazy start login
    Cut a release npm test && npm version patch && git push --follow-tags && gh release create lazy ship
    Set up a fresh checkout cp .env.example .env && npm ci && docker compose up -d && npm run db:migrate lazy up

    Write the steps once

    1. Write a recipe

      List the commands you run today in a lazy.yml file at the root of your repo.

    2. Give it a short name

      Call it ship, up or start. Whatever you would type without thinking.

    3. Run it

      lazydev runs each step in order and stops at the first failure, so a half-finished release never goes out.

    # lazy.yml
ship:
  - npm test
  - npm version patch
  - git push --follow-tags
  - gh release create --generate-notes

up:
  - cp -n .env.example .env
  - npm ci
  - docker compose up -d
  - npm run db:migrate
